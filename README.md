# Global Superstore Sales & Profitability Analysis (Power BI)

## Project Overview
This project focuses on analyzing sales performance, profitability, and customer behavior for a global retail business using **Power BI**.  
The goal was to transform raw transactional data into **actionable business insights** through effective data cleaning, modeling, and visual storytelling.

The dashboard is designed to support **executive decision-making** by answering key business questions related to growth, margins, regional performance, and customer segments.

## Tools Used  
- Power BI Desktop  
- Power Query (Data Cleaning & Transformation)  
- DAX (Measures & Time Intelligence)

---

## KPIs Used
The following key performance indicators were created using **DAX measures**:

- **Total Sales**
- **Total Profit**
- **Profit Margin (%)**
- **Average Order Value (AOV)**
- **Year-over-Year (YoY) Sales Growth**
- **Year-over-Year (YoY) Profit Growth**
- **Total Quantity Sold**

These KPIs were used across multiple dashboard pages including Executive Overview, Regional Performance, Product Analysis, and Customer Insights.

---

## Key Insights
- Revenue growth exists, but **cost structure and aggressive discounting are reducing overall profitability**
- **Consumer segment** generates the highest revenue, while the **Corporate segment delivers better profit margins**
- Business performance is **highly city-centric**, with a small number of cities contributing a large share of total profit
- Geographic expansion should prioritize **high-margin regions**, not just high-revenue markets
- Product performance varies significantly by region, indicating the need for a **region-specific product strategy**
- Corporate customers appear more reliable for **long-term, stable growth**, while Consumer customers drive volume with higher risk
